# 🇰🇭 SastraCode — Learn Programming in Khmer

**SastraCode** is a Khmer-focused online learning platform designed to make **programming and web development easier to learn in the Khmer language**.

The platform provides beginner-friendly programming tutorials, coding examples, educational videos, and learning resources for Cambodian students and aspiring developers.

> **Learn to Code. Learn in Khmer. Build Your Future. 🇰🇭**

---

## 🌐 About SastraCode

Learning programming can be difficult, especially when most programming resources are written in English.

**SastraCode** aims to solve this problem by providing easy-to-understand programming lessons and educational content in **Khmer**.

The platform is inspired by popular learning websites such as **W3Schools**, but focuses specifically on making programming education more accessible to **Khmer-speaking learners**.

### 🎯 Our Goal

Our goal is to help Cambodian students and beginner developers learn programming more easily through:

* 🇰🇭 Khmer-language explanations
* 💻 Interactive programming examples
* 📚 Step-by-step tutorials
* 🎥 Programming and technology videos
* 🧑‍💻 Practical coding examples
* 📝 Learning resources
* 🚀 Beginner-friendly content

## 🚀 Why SastraCode?

Most programming documentation and tutorials are written in English.

For many Cambodian students, understanding technical English can become an additional challenge.

**SastraCode** focuses on reducing that barrier by explaining programming concepts in **Khmer while keeping important technical terms in English**.

For example:

> **Variable (អថេរ)**
> Variable is a container used to store data in a program.

This approach allows learners to understand both the **Khmer explanation** and the **English programming terminology** commonly used in the software industry.
